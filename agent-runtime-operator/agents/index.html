Agents Module

The agents module covers the Agent and AgenticWorkforce custom resources — deploying agents from templates or custom images, configuring their tools and sub-agents, and grouping them into discoverable workforces.

How-to guides

  • Deploy a Template-Based Agent — deploy an agent using an operator-managed template image.

  • Deploy a Custom-Image Agent — deploy an agent using your own container image.

  • Propagate Headers to Tool Servers — forward HTTP headers from incoming A2A requests to MCP tool servers.

  • Delegate to a Sub-Agent — configure sub-agents and pick tool_call vs. transfer interaction.

  • Create an Agentic Workforce — group entry-point agents into an AgenticWorkforce.

Reference and explanation

  • Agent and AgenticWorkforce Reference — Agent and AgenticWorkforce CRD field listings.

  • Agents and Workforces — Agent CRD as a framework-agnostic contract, template vs. custom image trade-offs, the workforce concept.
