Level 2: Agent Runtime Operator

Controller Manager

Responsibility: Manages the lifecycle of agent workloads in Kubernetes

Interfaces: * Kubernetes API for resource management * Container registry for image pulls * Agent workloads for lifecycle management

Components: * Agent Controller * Reconciliation Engine * Status Manager

Custom Resource Definitions

Responsibility: Defines the schema and validation for agent specifications

Interfaces: * Kubernetes API server * kubectl and other Kubernetes tooling * Controller Manager

Components: * Agent CRD * Configuration Schema * Validation Webhooks

Level 3: Observability Dashboard

Trace Processor

Responsibility: Ingests and transforms OpenTelemetry traces into structured events

Interfaces: * OTLP/HTTP endpoint for trace ingestion * Internal event bus * WebSocket server for event distribution

Components: * OTLP Receiver * Event Transformer * Event Router

WebSocket Server

Responsibility: Provides real-time streaming of agent events

Interfaces: * WebSocket connections to clients * Internal event bus * HTTP API for connection management

Components: * Connection Manager * Event Broadcaster * Message Serializer

Component Interactions

Deployment Flow

  1. User creates Agent custom resource

  2. Controller Manager detects resource

  3. Controller creates Kubernetes workloads

  4. Agent workloads emit telemetry

  5. Dashboard processes traces

  6. Events streamed via WebSocket

Monitoring Flow

  1. Agents emit OpenTelemetry traces

  2. Trace Processor ingests and transforms

  3. Events published to internal bus

  4. WebSocket Server broadcasts to clients

  5. Clients receive real-time updates
