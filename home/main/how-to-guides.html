Installation (agentic-layer/agent-runtime-operator)

How to Install the Operator

Prerequisites

Before installing, ensure you have:

  • Kubernetes cluster (v1.19+)

  • kubectl configured to access your cluster

  • cert-manager installed (for webhooks)

Install cert-manager

If cert-manager isn’t already installed:

kubectl apply -f https://github.com/cert-manager/cert-manager/releases/download/v1.18.2/cert-manager.yaml

# Wait for cert-manager pods to be ready
kubectl wait --for=condition=ready pod -l app.kubernetes.io/name=cert-manager -n cert-manager --timeout=300s

Installation (agentic-layer/agent-runtime-operator) Methods

Method 1: From Release Manifests
# Install CRDs and operator from latest release
kubectl apply -f https://github.com/agentic-layer/agent-runtime-operator/releases/latest/download/install.yaml
Method 2: Using Kustomize
# Clone the repository
git clone https://github.com/agentic-layer/agent-runtime-operator
cd agent-runtime-operator

# Install CRDs
make install

# Deploy using kustomize
kubectl apply -k config/default
Method 3: Development Installation

For development or customization:

# Clone and build locally
git clone https://github.com/agentic-layer/agent-runtime-operator
cd agent-runtime-operator

# Install CRDs
make install

# Build and deploy
make docker-build docker-push IMG=<your-registry>/agent-runtime-operator:tag
make deploy IMG=<your-registry>/agent-runtime-operator:tag

Verify Installation

# Check operator pods
kubectl get pods -n agent-runtime-operator-system

# Verify CRDs are installed
kubectl get crds | grep runtime.agentic-layer.ai

# Check webhook configuration
kubectl get validatingwebhookconfiguration | grep agent-runtime-operator

How to Uninstall the Operator

# Delete all agent resources first
kubectl delete agents --all

# Remove the operator
make undeploy

# Remove CRDs (this will delete all agent resources)
make uninstall

How to Fix Common Problems

Image Pull Errors

Problem: ErrImagePull or ImagePullBackOff

Solutions: 1. Verify image exists and tag is correct 2. Check registry credentials 3. Ensure image registry is accessible from cluster

# Check image pull secrets
kubectl get secrets
kubectl describe secret <image-pull-secret>

# Test image pull manually
docker pull <image-name>

Resource Constraints

Problem: Pod stuck in Pending state

Solutions: 1. Check node resources: kubectl describe nodes 2. Reduce resource requests in agent spec 3. Add more nodes or use smaller resource limits

# Check node capacity
kubectl describe nodes | grep -A 5 "Allocated resources"

# Check resource quotas
kubectl describe quota

Webhook Certificate Issues

Problem: Webhook admission failures

Solutions: 1. Verify cert-manager is running 2. Check certificate status 3. Restart operator pods

# Check cert-manager
kubectl get pods -n cert-manager

# Check certificates
kubectl get certificates -A

# Restart operator
kubectl rollout restart deployment -n agent-runtime-operator-system agent-runtime-operator-controller-manager

Integration Patterns (agentic-layer/observability-dashboard)

How to Integrate with Google ADK

Integrate Google Agent Development Kit with observability monitoring.

from adk import Agent
from opentelemetry import trace
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor
from opentelemetry.instrumentation.requests import RequestsInstrumentor

# Set up OpenTelemetry
trace.set_tracer_provider(TracerProvider())
tracer = trace.get_tracer(__name__)

otlp_exporter = OTLPSpanExporter(
    endpoint="http://observability-dashboard:8000/v1/traces"
)
span_processor = BatchSpanProcessor(otlp_exporter)
trace.get_tracer_provider().add_span_processor(span_processor)

# Auto-instrument HTTP requests
RequestsInstrumentor().instrument()

class ObservableAgent(Agent):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.conversation_id = str(uuid.uuid4())
        self.tracer = trace.get_tracer(self.__class__.__name__)

    async def process(self, request):
        with self.tracer.start_as_current_span("adk.agent.process") as span:
            span.set_attribute("conversation.id", self.conversation_id)
            span.set_attribute("agent.framework", "google-adk")
            span.set_attribute("agent.name", self.name)
            span.set_attribute("agent.version", "1.0.0")

            return await super().process(request)

    async def call_llm(self, prompt: str, **kwargs):
        with self.tracer.start_as_current_span("llm.call") as span:
            span.set_attribute("conversation.id", self.conversation_id)
            span.set_attribute("llm.prompt", prompt)
            span.set_attribute("agent.name", self.name)

            result = await super().call_llm(prompt, **kwargs)

            span.set_attribute("llm.response", result.get("text", ""))
            span.set_attribute("llm.model", kwargs.get("model", "unknown"))

            return result

How to Integrate with AutoGen

Set up monitoring for Microsoft AutoGen multi-agent conversations.

from autogen import AssistantAgent, UserProxyAgent, GroupChat, GroupChatManager
from opentelemetry import trace
import uuid

tracer = trace.get_tracer(__name__)

class ObservableAssistantAgent(AssistantAgent):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.conversation_id = str(uuid.uuid4())

    def generate_reply(self, messages, sender, **kwargs):
        with tracer.start_as_current_span("autogen.generate_reply") as span:
            span.set_attribute("conversation.id", self.conversation_id)
            span.set_attribute("agent.framework", "autogen")
            span.set_attribute("agent.name", self.name)
            span.set_attribute("sender", sender.name if sender else "unknown")
            span.set_attribute("message_count", len(messages))

            # Extract last message for prompt tracking
            if messages:
                last_message = messages[-1].get("content", "")
                span.set_attribute("llm.prompt", last_message)

            reply = super().generate_reply(messages, sender, **kwargs)

            if isinstance(reply, str):
                span.set_attribute("llm.response", reply)

            return reply

class ObservableGroupChatManager(GroupChatManager):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.conversation_id = str(uuid.uuid4())

    def select_speaker(self, last_speaker, selector):
        with tracer.start_as_current_span("autogen.select_speaker") as span:
            span.set_attribute("conversation.id", self.conversation_id)
            span.set_attribute("agent.name", "group_chat_manager")
            span.set_attribute("last_speaker", last_speaker.name)

            selected = super().select_speaker(last_speaker, selector)

            span.set_attribute("selected_speaker", selected.name if selected else "none")
            return selected

How to Integrate with LangChain

Monitor LangChain agents and chains.

from langchain.agents import AgentExecutor, create_openai_functions_agent
from langchain.tools import BaseTool
from langchain_core.callbacks import BaseCallbackHandler
from opentelemetry import trace
import uuid

tracer = trace.get_tracer(__name__)

class ObservabilityCallback(BaseCallbackHandler):
    def __init__(self, conversation_id: str):
        self.conversation_id = conversation_id

    def on_llm_start(self, serialized, prompts, **kwargs):
        self.current_span = tracer.start_span("llm.call")
        self.current_span.set_attribute("conversation.id", self.conversation_id)
        self.current_span.set_attribute("agent.framework", "langchain")

        if prompts:
            self.current_span.set_attribute("llm.prompt", prompts[0])

    def on_llm_end(self, response, **kwargs):
        if hasattr(self, 'current_span'):
            generations = response.generations[0] if response.generations else []
            if generations:
                text = generations[0].text
                self.current_span.set_attribute("llm.response", text)

            self.current_span.end()

    def on_tool_start(self, serialized, input_str, **kwargs):
        self.tool_span = tracer.start_span("tool.call")
        self.tool_span.set_attribute("conversation.id", self.conversation_id)
        self.tool_span.set_attribute("tool.name", serialized.get("name", "unknown"))
        self.tool_span.set_attribute("tool.params", str(input_str))

    def on_tool_end(self, output, **kwargs):
        if hasattr(self, 'tool_span'):
            self.tool_span.set_attribute("tool.result", str(output))
            self.tool_span.set_attribute("tool.status", "success")
            self.tool_span.end()

# Usage
conversation_id = str(uuid.uuid4())
callback = ObservabilityCallback(conversation_id)

agent_executor = AgentExecutor(
    agent=agent,
    tools=tools,
    callbacks=[callback],
    verbose=True
)

How to Set Up Load Balancing

Configure load balancing for high-throughput scenarios.

# nginx.conf
upstream observability_backend {
    least_conn;
    server observability-1:8000 max_fails=3 fail_timeout=30s;
    server observability-2:8000 max_fails=3 fail_timeout=30s;
    server observability-3:8000 max_fails=3 fail_timeout=30s;
}

server {
    listen 80;
    server_name observability.yourdomain.com;

    location /v1/traces {
        proxy_pass http://observability_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_connect_timeout 5s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    location /ws {
        proxy_pass http://observability_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 86400;
    }
}

Monitoring and Alerting (agentic-layer/observability-dashboard)

How to Set Up Health Checks

Implement comprehensive health monitoring.

# custom_health.py
from fastapi import APIRouter, HTTPException
from typing import Dict, Any
import asyncio
import time
from datetime import datetime, timedelta

router = APIRouter()

class HealthChecker:
    def __init__(self):
        self.last_trace_received = None
        self.websocket_connections = 0
        self.error_count = 0
        self.start_time = datetime.utcnow()

    async def check_system_health(self) -> Dict[str, Any]:
        """Comprehensive health check"""
        health_status = {
            "status": "healthy",
            "timestamp": datetime.utcnow().isoformat(),
            "uptime_seconds": (datetime.utcnow() - self.start_time).total_seconds(),
            "checks": {}
        }

        # Check trace ingestion
        if self.last_trace_received:
            time_since_last_trace = (datetime.utcnow() - self.last_trace_received).total_seconds()
            health_status["checks"]["trace_ingestion"] = {
                "status": "healthy" if time_since_last_trace < 300 else "warning",
                "last_received_seconds_ago": time_since_last_trace
            }
        else:
            health_status["checks"]["trace_ingestion"] = {
                "status": "unknown",
                "message": "No traces received yet"
            }

        # Check WebSocket connections
        health_status["checks"]["websocket"] = {
            "status": "healthy",
            "active_connections": self.websocket_connections
        }

        # Check error rate
        error_rate = self.error_count / max(1, (datetime.utcnow() - self.start_time).total_seconds())
        health_status["checks"]["error_rate"] = {
            "status": "healthy" if error_rate < 0.1 else "unhealthy",
            "errors_per_second": round(error_rate, 4)
        }

        # Overall status
        check_statuses = [check["status"] for check in health_status["checks"].values()]
        if "unhealthy" in check_statuses:
            health_status["status"] = "unhealthy"
        elif "warning" in check_statuses:
            health_status["status"] = "warning"

        return health_status

health_checker = HealthChecker()

@router.get("/health/detailed")
async def detailed_health():
    return await health_checker.check_system_health()

@router.get("/health/liveness")
async def liveness():
    """Simple liveness probe for Kubernetes"""
    return {"status": "alive"}

@router.get("/health/readiness")
async def readiness():
    """Readiness probe - checks if service can handle requests"""
    health = await health_checker.check_system_health()
    if health["status"] == "unhealthy":
        raise HTTPException(status_code=503, detail=health)
    return health

How to Set Up Prometheus Metrics

Export metrics for Prometheus monitoring.

# metrics.py
from prometheus_client import Counter, Histogram, Gauge, generate_latest
from fastapi import Response
import time

# Define metrics
traces_received_total = Counter(
    'traces_received_total',
    'Total number of traces received',
    ['status']
)

trace_processing_duration = Histogram(
    'trace_processing_duration_seconds',
    'Time spent processing traces'
)

websocket_connections_active = Gauge(
    'websocket_connections_active',
    'Number of active WebSocket connections'
)

events_broadcasted_total = Counter(
    'events_broadcasted_total',
    'Total number of events broadcast',
    ['event_type']
)

class MetricsCollector:
    def __init__(self):
        self.start_time = time.time()

    def record_trace_received(self, status: str = "success"):
        traces_received_total.labels(status=status).inc()

    def record_trace_processing_time(self, duration: float):
        trace_processing_duration.observe(duration)

    def set_websocket_connections(self, count: int):
        websocket_connections_active.set(count)

    def record_event_broadcast(self, event_type: str):
        events_broadcasted_total.labels(event_type=event_type).inc()

metrics_collector = MetricsCollector()

async def metrics_handler():
    """Prometheus metrics endpoint"""
    return Response(
        generate_latest(),
        media_type="text/plain"
    )

# Integration example

# high_throughput_config.py
import asyncio
from typing import List
from opentelemetry.proto.trace.v1 import trace_pb2

class HighThroughputProcessor:
    def __init__(self, batch_size: int = 100, flush_interval: float = 1.0):
        self.batch_size = batch_size
        self.flush_interval = flush_interval
        self.pending_spans: List[trace_pb2.Span] = []
        self.last_flush = asyncio.get_event_loop().time()

    async def add_span(self, span: trace_pb2.Span):
        """Add span to processing batch"""
        self.pending_spans.append(span)

        # Flush if batch is full or time threshold reached
        current_time = asyncio.get_event_loop().time()
        if (len(self.pending_spans) >= self.batch_size or
            current_time - self.last_flush >= self.flush_interval):
            await self.flush_batch()

    async def flush_batch(self):
        """Process accumulated spans in batch"""
        if not self.pending_spans:
            return

        batch = self.pending_spans.copy()
        self.pending_spans.clear()
        self.last_flush = asyncio.get_event_loop().time()

        # Process batch concurrently
        tasks = [self.process_span(span) for span in batch]
        await asyncio.gather(*tasks, return_exceptions=True)

# Connection pooling for WebSocket broadcasts
class ConnectionPool:
    def __init__(self, max_connections: int = 1000):
        self.max_connections = max_connections
        self.connections = {}
        self.connection_count = 0

    async def add_connection(self, connection_id: str, websocket):
        if self.connection_count >= self.max_connections:
            await websocket.close(code=1013, reason="Server overloaded")
            return False

        self.connections[connection_id] = websocket
        self.connection_count += 1
        return True

    async def broadcast_event(self, event: dict, conversation_id: str = None):
        """Efficiently broadcast to relevant connections"""
        tasks = []

        for conn_id, websocket in self.connections.items():
            # Filter by conversation if specified
            if conversation_id and not conn_id.endswith(f":{conversation_id}"):
                continue

            tasks.append(self.send_to_connection(websocket, event))

        # Send all messages concurrently
        if tasks:
            await asyncio.gather(*tasks, return_exceptions=True)

    async def send_to_connection(self, websocket, event):
        try:
            await websocket.send_json(event)
        except Exception:
            # Connection is dead, remove it
            await self.remove_connection(websocket)

# memory_optimization.py
import gc
import weakref
from collections import deque
from typing import Dict, Any
import asyncio

class EventBuffer:
    """Memory-efficient circular buffer for events"""

    def __init__(self, max_size: int = 10000):
        self.buffer = deque(maxlen=max_size)
        self.conversation_indexes: Dict[str, list] = {}

    def add_event(self, event: dict):
        """Add event with memory management"""
        # Add to main buffer
        self.buffer.append(event)

        # Update conversation index
        conv_id = event.get("conversation_id")
        if conv_id:
            if conv_id not in self.conversation_indexes:
                self.conversation_indexes[conv_id] = []

            self.conversation_indexes[conv_id].append(len(self.buffer) - 1)

            # Limit conversation history
            if len(self.conversation_indexes[conv_id]) > 1000:
                self.conversation_indexes[conv_id] = \
                    self.conversation_indexes[conv_id][-1000:]

    def get_conversation_events(self, conversation_id: str, limit: int = 100):
        """Get recent events for conversation"""
        if conversation_id not in self.conversation_indexes:
            return []

        indexes = self.conversation_indexes[conversation_id][-limit:]
        return [self.buffer[i] for i in indexes if i < len(self.buffer)]

    def cleanup_old_conversations(self):
        """Remove old conversation indexes"""
        active_conversations = set()

        # Find active conversations in recent events
        for event in list(self.buffer)[-1000:]:
            conv_id = event.get("conversation_id")
            if conv_id:
                active_conversations.add(conv_id)

        # Remove inactive conversation indexes
        inactive = set(self.conversation_indexes.keys()) - active_conversations
        for conv_id in inactive:
            del self.conversation_indexes[conv_id]

class WeakConnectionManager:
    """Connection manager using weak references"""

    def __init__(self):
        self.global_connections = weakref.WeakSet()
        self.conversation_connections = {}

    def add_global_connection(self, websocket):
        self.global_connections.add(websocket)

    def add_conversation_connection(self, websocket, conversation_id: str):
        if conversation_id not in self.conversation_connections:
            self.conversation_connections[conversation_id] = weakref.WeakSet()
        self.conversation_connections[conversation_id].add(websocket)

    async def broadcast_event(self, event: dict):
        """Broadcast with automatic cleanup of dead connections"""
        # Global broadcast
        dead_connections = []
        for ws in list(self.global_connections):
            try:
                await ws.send_json(event)
            except Exception:
                dead_connections.append(ws)

        # Remove dead connections (they'll be garbage collected)
        for ws in dead_connections:
            self.global_connections.discard(ws)

        # Conversation-specific broadcast
        conversation_id = event.get("conversation_id")
        if conversation_id and conversation_id in self.conversation_connections:
            connections = self.conversation_connections[conversation_id]
            dead_connections = []

            for ws in list(connections):
                try:
                    await ws.send_json(event)
                except Exception:
                    dead_connections.append(ws)

            for ws in dead_connections:
                connections.discard(ws)

class WebSocketAuth:
    def __init__(self, secret_key: str):
        self.secret_key = secret_key

    def create_token(self, user_id: str, conversation_ids: list = None) -> str:
        """Create JWT token for WebSocket authentication"""
        payload = {
            "user_id": user_id,
            "conversation_ids": conversation_ids or [],
            "iat": time.time(),
            "exp": time.time() + 3600  # 1 hour expiration
        }
        return jwt.encode(payload, self.secret_key, algorithm="HS256")

    def verify_token(self, token: str) -> Optional[dict]:
        """Verify JWT token"""
        try:
            payload = jwt.decode(token, self.secret_key, algorithms=["HS256"])
            return payload
        except jwt.InvalidTokenError:
            return None

    async def authenticate_websocket(self, websocket: WebSocket, token: str = None):
        """Authenticate WebSocket connection"""
        if not token:
            await websocket.close(code=4001, reason="Authentication required")
            return None

        payload = self.verify_token(token)
        if not payload:
            await websocket.close(code=4001, reason="Invalid token")
            return None

        return payload

# Rate limiting for WebSocket connections
from collections import defaultdict
import asyncio

class WebSocketRateLimiter:
    def __init__(self, max_connections_per_ip: int = 10, max_messages_per_minute: int = 100):
        self.max_connections_per_ip = max_connections_per_ip
        self.max_messages_per_minute = max_messages_per_minute
        self.connection_counts = defaultdict(int)
        self.message_counts = defaultdict(list)

    async def check_connection_limit(self, client_ip: str) -> bool:
        """Check if IP has exceeded connection limit"""
        if self.connection_counts[client_ip] >= self.max_connections_per_ip:
            return False

        self.connection_counts[client_ip] += 1
        return True

    async def check_message_rate(self, client_ip: str) -> bool:
        """Check if IP has exceeded message rate limit"""
        now = time.time()
        minute_ago = now - 60

        # Clean old messages
        self.message_counts[client_ip] = [
            msg_time for msg_time in self.message_counts[client_ip]
            if msg_time > minute_ago
        ]

        if len(self.message_counts[client_ip]) >= self.max_messages_per_minute:
            return False

        self.message_counts[client_ip].append(now)
        return True

    async def disconnect_client(self, client_ip: str):
        """Clean up when client disconnects"""
        self.connection_counts[client_ip] = max(0, self.connection_counts[client_ip] - 1)

# Input validation and sanitization
import re
from typing import Any

class InputValidator:
    UUID_PATTERN = re.compile(
        r'^[0-9a-f]{8}-[0-9a-f]{4}-4[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$',
        re.IGNORECASE
    )

    @classmethod
    def validate_conversation_id(cls, conversation_id: str) -> bool:
        """Validate conversation ID format"""
        return bool(cls.UUID_PATTERN.match(conversation_id))

    @classmethod
    def sanitize_event_data(cls, event: dict) -> dict:
        """Sanitize event data to prevent injection attacks"""
        sanitized = {}

        for key, value in event.items():
            # Sanitize key
            if isinstance(key, str) and key.isalnum():
                # Sanitize value
                if isinstance(value, str):
                    # Remove potential XSS/injection content
                    sanitized_value = re.sub(r'[<>"\']', '', value)
                    sanitized[key] = sanitized_value[:1000]  # Limit length
                elif isinstance(value, (int, float, bool)):
                    sanitized[key] = value
                elif isinstance(value, dict):
                    sanitized[key] = cls.sanitize_event_data(value)

        return sanitized

# Secure WebSocket endpoint implementation
async def secure_websocket_endpoint(
    websocket: WebSocket,
    conversation_id: str = None,
    token: str = None
):
    """Secure WebSocket endpoint with authentication and rate limiting"""

    client_ip = websocket.client.host
    auth = WebSocketAuth("your-secret-key")
    rate_limiter = WebSocketRateLimiter()

    # Check connection limit
    if not await rate_limiter.check_connection_limit(client_ip):
        await websocket.close(code=4029, reason="Too many connections")
        return

    # Authenticate
    user_data = await auth.authenticate_websocket(websocket, token)
    if not user_data:
        return

    # Validate conversation ID
    if conversation_id and not InputValidator.validate_conversation_id(conversation_id):
        await websocket.close(code=4000, reason="Invalid conversation ID")
        return

    # Check authorization for conversation
    if conversation_id and conversation_id not in user_data.get("conversation_ids", []):
        await websocket.close(code=4003, reason="Unauthorized for conversation")
        return

    try:
        await websocket.accept()

        while True:
            # Rate limit messages
            if not await rate_limiter.check_message_rate(client_ip):
                await websocket.close(code=4029, reason="Rate limit exceeded")
                break

            # Handle connection
            await handle_websocket_message(websocket, conversation_id)

    except Exception as e:
        print(f"WebSocket error: {e}")
    finally:
        await rate_limiter.disconnect_client(client_ip)

How to Implement Access Control

Control access to specific conversations and events.

# access_control.py
from enum import Enum
from typing import Set, Dict, Optional
from dataclasses import dataclass

class Permission(Enum):
    READ_GLOBAL = "read:global"
    READ_CONVERSATION = "read:conversation"
    WRITE_TRACES = "write:traces"
    ADMIN = "admin"

@dataclass
class User:
    user_id: str
    permissions: Set[Permission]
    conversation_access: Set[str]  # Conversation IDs user can access
    organization_id: Optional[str] = None

class AccessControlManager:
    def __init__(self):
        self.users: Dict[str, User] = {}
        self.organization_conversations: Dict[str, Set[str]] = {}

    def add_user(self, user: User):
        """Register a user"""
        self.users[user.user_id] = user

    def can_access_global_stream(self, user_id: str) -> bool:
        """Check if user can access global event stream"""
        user = self.users.get(user_id)
        return user and Permission.READ_GLOBAL in user.permissions

    def can_access_conversation(self, user_id: str, conversation_id: str) -> bool:
        """Check if user can access specific conversation"""
        user = self.users.get(user_id)
        if not user:
            return False

        # Admin can access everything
        if Permission.ADMIN in user.permissions:
            return True

        # Check direct conversation access
        if conversation_id in user.conversation_access:
            return True

        # Check organization-level access
        if user.organization_id:
            org_conversations = self.organization_conversations.get(user.organization_id, set())
            return conversation_id in org_conversations

        return False

    def can_write_traces(self, user_id: str) -> bool:
        """Check if user can send traces"""
        user = self.users.get(user_id)
        return user and (
            Permission.WRITE_TRACES in user.permissions or
            Permission.ADMIN in user.permissions
        )

    def filter_events_for_user(self, user_id: str, events: list) -> list:
        """Filter events based on user permissions"""
        user = self.users.get(user_id)
        if not user:
            return []

        if Permission.ADMIN in user.permissions:
            return events

        filtered = []
        for event in events:
            conversation_id = event.get("conversation_id")
            if conversation_id and self.can_access_conversation(user_id, conversation_id):
                filtered.append(event)

        return filtered
