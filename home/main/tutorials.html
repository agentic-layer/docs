Getting Started Tutorial (Agent Runtime Operator) ({repo-name})

This tutorial will walk you through setting up the Agent Runtime Operator and deploying your first agent. By the end, you’ll have a working operator deployment and understand the basic workflow.

What You’ll Learn

  • How to set up a local Kubernetes cluster

  • How to deploy the Agent Runtime Operator

  • How to create and deploy your first agent

  • How to verify your deployment works

What You’ll Need

  • Docker installed and running

  • kubectl command-line tool

  • kind (Kubernetes in Docker) for local testing

Step 1: Set Up Your Environment

First, let’s create a local Kubernetes cluster using kind:

# Create a new kind cluster
kind create cluster --name agent-operator-tutorial

# Verify the cluster is running
kubectl cluster-info --context kind-agent-operator-tutorial

Step 2: Install Prerequisites

The operator requires cert-manager for webhook certificates:

# Install cert-manager
kubectl apply -f https://github.com/cert-manager/cert-manager/releases/download/v1.18.2/cert-manager.yaml

# Wait for cert-manager to be ready
kubectl wait --for=condition=ready pod -l app.kubernetes.io/name=cert-manager -n cert-manager --timeout=300s

Step 3: Clone and Deploy the Operator

# Clone the repository
git clone https://github.com/agentic-layer/agent-runtime-operator
cd agent-runtime-operator

# Install the Custom Resource Definitions
make install

# Build the operator container image
make docker-build

# Load the image into your kind cluster
make kind-load

# Deploy the operator
make deploy

Step 4: Verify the Operator

Check that the operator is running:

# Check the operator pods
kubectl get pods -n agent-runtime-operator-system

# You should see output like:
# NAME                                                     READY   STATUS    RESTARTS   AGE
# agent-runtime-operator-controller-manager-xxxxx         2/2     Running   0          60s

Step 5: Deploy Your First Agent

Create a simple agent configuration:

cat << EOF > my-first-agent.yaml
apiVersion: runtime.agentic-layer.ai/v1alpha1
kind: Agent
metadata:
  name: my-first-agent
spec:
  framework: google-adk
  image: eu.gcr.io/agentic-layer/weather-agent:0.1.2
  protocols:
    - type: A2A
  replicas: 1
EOF

# Apply the configuration
kubectl apply -f my-first-agent.yaml

Step 6: Verify Your Agent

Check that your agent is deployed and running:

# Check the agent resource
kubectl get agents

# Check the created deployment
kubectl get deployments

# Check the running pods
kubectl get pods

You should see your agent pod in a "Running" state.

What You’ve Accomplished

Congratulations! You’ve successfully:

✅ Set up a local Kubernetes cluster ✅ Deployed the Agent Runtime Operator ✅ Created and deployed your first agent ✅ Verified everything is working

Next Steps

Now that you have the basics working, you can:

  • Learn how to configure different agent types

  • Explore the complete custom resource reference

  • Understand how the operator works under the hood

Troubleshooting

If you encounter issues:

  1. Operator not starting: Check the logs with kubectl logs -n agent-runtime-operator-system deployment/agent-runtime-operator-controller-manager

  2. Agent not deploying: Check the agent status with kubectl describe agent my-first-agent

  3. Pods stuck pending: Check resource constraints with kubectl describe pod <pod-name>

Clean Up

To clean up your tutorial environment:

# Delete the agent
kubectl delete agent my-first-agent

# Delete the operator
make undeploy

# Delete the kind cluster
kind delete cluster --name agent-operator-tutorial

Step 2: Create Your First Instrumented Agent

Create a simple agent that you can monitor:

# tutorial_agent.py
import uuid
import time
import asyncio
from opentelemetry import trace
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor

# Set up OpenTelemetry
trace.set_tracer_provider(TracerProvider())
tracer = trace.get_tracer(__name__)

# Configure OTLP exporter
otlp_exporter = OTLPSpanExporter(
    endpoint="http://localhost:8000/v1/traces",
    headers={"Content-Type": "application/x-protobuf"}
)

span_processor = BatchSpanProcessor(otlp_exporter)
trace.get_tracer_provider().add_span_processor(span_processor)

class WeatherAgent:
    def __init__(self, name: str):
        self.name = name
        self.conversation_id = str(uuid.uuid4())
        print(f"Agent created with conversation ID: {self.conversation_id}")

    def start(self):
        """Start the agent with tracing"""
        with tracer.start_as_current_span("agent.start") as span:
            span.set_attribute("agent.name", self.name)
            span.set_attribute("conversation.id", self.conversation_id)
            span.set_attribute("agent.type", "weather-assistant")
            span.set_attribute("agent.version", "1.0.0")

            print(f"Agent {self.name} started")
            time.sleep(0.5)  # Simulate initialization

    def process_query(self, user_query: str):
        """Process a user query with LLM and tool calls"""
        # Simulate LLM call
        with tracer.start_as_current_span("llm.call") as span:
            span.set_attribute("conversation.id", self.conversation_id)
            span.set_attribute("llm.model", "gpt-4")
            span.set_attribute("llm.prompt", user_query)

            # Simulate processing time
            time.sleep(1.2)

            response = f"I'll help you check the weather. Let me use the weather tool."
            span.set_attribute("llm.response", response)
            span.set_attribute("llm.tokens.prompt", len(user_query.split()))
            span.set_attribute("llm.tokens.completion", len(response.split()))
            span.set_attribute("llm.tokens.total", len(user_query.split()) + len(response.split()))

        # Simulate tool call
        with tracer.start_as_current_span("tool.call") as span:
            span.set_attribute("conversation.id", self.conversation_id)
            span.set_attribute("tool.name", "get_weather")
            span.set_attribute("tool.params", '{"location": "New York", "units": "celsius"}')

            time.sleep(0.8)  # Simulate API call

            result = '{"temperature": 22, "condition": "sunny", "humidity": 60}'
            span.set_attribute("tool.result", result)
            span.set_attribute("tool.status", "success")

        return "The weather in New York is 22°C and sunny with 60% humidity."

    def stop(self):
        """Stop the agent"""
        with tracer.start_as_current_span("agent.stop") as span:
            span.set_attribute("agent.name", self.name)
            span.set_attribute("conversation.id", self.conversation_id)
            span.set_attribute("stop_reason", "completed")
            span.set_attribute("runtime_seconds", 30)

            print(f"Agent {self.name} stopped")

if __name__ == "__main__":
    # Create and run the agent
    agent = WeatherAgent("weather-bot")

    agent.start()
    result = agent.process_query("What's the weather like in New York?")
    print(f"Result: {result}")
    agent.stop()

    # Give time for traces to be sent
    time.sleep(2)

Run your agent:

python tutorial_agent.py

Step 1: Create a Multi-Agent System

# multi_agent_system.py
import uuid
import time
import asyncio
from typing import List
from opentelemetry import trace

# Use the same tracer setup from Tutorial 1

class Coordinator:
    def __init__(self):
        self.name = "coordinator"
        self.conversation_id = str(uuid.uuid4())
        print(f"Conversation ID: {self.conversation_id}")

    def delegate_task(self, task: str, agent_name: str):
        """Delegate task to specific agent"""
        with tracer.start_as_current_span("agent.message") as span:
            span.set_attribute("conversation.id", self.conversation_id)
            span.set_attribute("agent.name", self.name)
            span.set_attribute("message_type", "request")
            span.set_attribute("target_agent", agent_name)
            span.set_attribute("message_content", task)

            print(f"Delegating to {agent_name}: {task}")

class SpecializedAgent:
    def __init__(self, name: str, specialty: str, conversation_id: str):
        self.name = name
        self.specialty = specialty
        self.conversation_id = conversation_id

    def start(self):
        with tracer.start_as_current_span("agent.start") as span:
            span.set_attribute("agent.name", self.name)
            span.set_attribute("conversation.id", self.conversation_id)
            span.set_attribute("agent.type", self.specialty)
        print(f"{self.name} agent ready ({self.specialty})")

    def process_request(self, request: str):
        """Process request using LLM and tools"""
        # LLM reasoning
        with tracer.start_as_current_span("llm.call") as span:
            span.set_attribute("conversation.id", self.conversation_id)
            span.set_attribute("agent.name", self.name)
            span.set_attribute("llm.model", "gpt-4")
            span.set_attribute("llm.prompt", f"As a {self.specialty} specialist: {request}")

            time.sleep(1.0)  # Simulate processing
            response = f"Processing {request} using {self.specialty} expertise"
            span.set_attribute("llm.response", response)

        # Tool usage
        with tracer.start_as_current_span("tool.call") as span:
            span.set_attribute("conversation.id", self.conversation_id)
            span.set_attribute("agent.name", self.name)
            span.set_attribute("tool.name", f"{self.specialty}_tool")
            span.set_attribute("tool.params", f'{{"query": "{request}"}}')

            time.sleep(0.7)
            result = f"Completed {self.specialty} analysis"
            span.set_attribute("tool.result", result)
            span.set_attribute("tool.status", "success")

        return result

# Run the multi-agent system
coordinator = Coordinator()
conversation_id = coordinator.conversation_id

# Create specialized agents
weather_agent = SpecializedAgent("weather-expert", "meteorology", conversation_id)
traffic_agent = SpecializedAgent("traffic-expert", "transportation", conversation_id)

# Start agents
weather_agent.start()
traffic_agent.start()

# Coordinate tasks
coordinator.delegate_task("Check weather for road trip", "weather-expert")
weather_result = weather_agent.process_request("Weather forecast for highway route")

coordinator.delegate_task("Find optimal route", "traffic-expert")
traffic_result = traffic_agent.process_request("Traffic analysis for route planning")

print(f"Weather: {weather_result}")
print(f"Traffic: {traffic_result}")

time.sleep(2)  # Allow traces to be sent

Step 2: Enhanced Monitoring Dashboard

Create an improved monitoring interface:

<!DOCTYPE html>
<html>
<head>
    <title>Multi-Agent Monitor</title>
    <style>
        body { font-family: Arial, sans-serif; margin: 20px; }
        .controls { margin: 20px 0; }

        .traffic-expert { border-left-color: #28a745; }

        .conversation-id {
            background: #e9ecef;
            padding: 10px;
            margin: 10px 0;
            border-radius: 4px;
            font-family: monospace;
        }
    </style>
</head>
<body>
    <h1>Multi-Agent System Monitor</h1>

    <div class="controls">
        <input type="text" id="conversationId" placeholder="Enter Conversation ID" style="width: 300px;">
        <button onclick="connect()">Connect to Conversation</button>
        <button onclick="connectGlobal()">Global Stream</button>
        <button onclick="clearEvents()">Clear</button>
    </div>

    <div id="connectionStatus"></div>
    <div id="conversationInfo" class="conversation-id" style="display: none;"></div>

    <div id="agentColumns">
        <div class="agent-section">
            <h3>Coordinator Events</h3>
            <div id="coordinator-events"></div>
        </div>
        <div class="agent-section">
            <h3>Specialist Agents</h3>
            <div id="specialist-events"></div>
        </div>
    </div>

    <div class="agent-section" style="width: 98%;">
        <h3>All Events (Chronological)</h3>
        <div id="all-events"></div>
    </div>

    <script>
        let ws = null;
        let currentConversation = null;

        function connect() {
            const conversationId = document.getElementById('conversationId').value;
            if (!conversationId) {
                alert('Please enter a conversation ID');
                return;
            }

            if (ws) ws.close();

            ws = new WebSocket(`ws://localhost:8000/ws/${conversationId}`);
            currentConversation = conversationId;
            setupWebSocket();
        }

        function connectGlobal() {
            if (ws) ws.close();

            ws = new WebSocket('ws://localhost:8000/ws');
            currentConversation = null;
            setupWebSocket();
        }

        function setupWebSocket() {
            const status = document.getElementById('connectionStatus');
            const info = document.getElementById('conversationInfo');

            ws.onopen = () => {
                const connectionType = currentConversation ?
                    `conversation-specific (${currentConversation})` : 'global';
                status.innerHTML = `<span style="color: green;">Connected to ${connectionType} stream</span>`;

                if (currentConversation) {
                    info.textContent = `Monitoring conversation: ${currentConversation}`;
                    info.style.display = 'block';
                } else {
                    info.style.display = 'none';
                }
            };

            ws.onmessage = (event) => {
                const data = JSON.parse(event.data);
                addEvent(data);
            };

            ws.onclose = () => {
                status.innerHTML = '<span style="color: red;">Disconnected</span>';
            };
        }

        function addEvent(eventData) {
            const agentName = eventData.agent_name || 'unknown';
            const timestamp = new Date(eventData.timestamp).toLocaleTimeString();

            const eventDiv = document.createElement('div');
            eventDiv.className = `event ${agentName}`;

            let content = `<strong>${eventData.event_type}</strong> - ${agentName}`;

            if (eventData.event_type === 'agent.message') {
                content += `<br>→ ${eventData.target_agent}: ${eventData.message_content}`;
            } else if (eventData.event_type === 'llm.call') {
                content += `<br>💭 ${eventData.prompt?.substring(0, 50)}...`;
            } else if (eventData.event_type === 'tool.output') {
                content += `<br>🔧 ${eventData.tool_name}: ${eventData.tool_status}`;
            }

            content += `<div class="timestamp">${timestamp}</div>`;
            eventDiv.innerHTML = content;

            // Add to appropriate sections
            const allEvents = document.getElementById('all-events');
            allEvents.insertBefore(eventDiv.cloneNode(true), allEvents.firstChild);

            if (agentName === 'coordinator') {
                const coordinatorEvents = document.getElementById('coordinator-events');
                coordinatorEvents.insertBefore(eventDiv, coordinatorEvents.firstChild);
            } else {
                const specialistEvents = document.getElementById('specialist-events');
                specialistEvents.insertBefore(eventDiv, specialistEvents.firstChild);
            }
        }

        function clearEvents() {
            document.getElementById('all-events').innerHTML = '';
            document.getElementById('coordinator-events').innerHTML = '';
            document.getElementById('specialist-events').innerHTML = '';
        }
    </script>
</body>
</html>

Step 1: Create an Agent with Intentional Issues

# debugging_agent.py
import uuid
import time
import random
from opentelemetry import trace
from opentelemetry.trace import Status, StatusCode

# Use the same tracer setup from previous tutorials

class ProblematicAgent:
    def __init__(self, name: str):
        self.name = name
        self.conversation_id = str(uuid.uuid4())
        print(f"Debugging session: {self.conversation_id}")

    def start(self):
        with tracer.start_as_current_span("agent.start") as span:
            span.set_attribute("agent.name", self.name)
            span.set_attribute("conversation.id", self.conversation_id)
            span.set_attribute("agent.type", "debug-example")
        print(f"Started {self.name}")

    def unreliable_llm_call(self, prompt: str):
        """LLM call that sometimes fails"""
        with tracer.start_as_current_span("llm.call") as span:
            span.set_attribute("conversation.id", self.conversation_id)
            span.set_attribute("agent.name", self.name)
            span.set_attribute("llm.model", "gpt-4")
            span.set_attribute("llm.prompt", prompt)

            # Simulate random failures
            if random.random() < 0.3:  # 30% failure rate
                span.record_exception(Exception("Rate limit exceeded"))
                span.set_status(Status(StatusCode.ERROR, "LLM request failed"))

                # Generate error event
                with tracer.start_as_current_span("error") as error_span:
                    error_span.set_attribute("conversation.id", self.conversation_id)
                    error_span.set_attribute("agent.name", self.name)
                    error_span.set_attribute("error_type", "RateLimitError")
                    error_span.set_attribute("error_message", "Rate limit exceeded")
                    error_span.set_attribute("error_code", "RATE_LIMIT_EXCEEDED")

                raise Exception("Rate limit exceeded")

            # Simulate slow responses
            delay = random.uniform(0.5, 3.0)
            time.sleep(delay)

            response = f"Processed: {prompt[:30]}... (took {delay:.1f}s)"
            token_count = len(prompt.split()) + len(response.split())

            span.set_attribute("llm.response", response)
            span.set_attribute("llm.tokens.prompt", len(prompt.split()))
            span.set_attribute("llm.tokens.completion", len(response.split()))
            span.set_attribute("llm.tokens.total", token_count)
            span.set_attribute("llm.response_time_ms", int(delay * 1000))

            return response

    def memory_intensive_tool(self, data_size: str):
        """Tool that uses varying amounts of resources"""
        with tracer.start_as_current_span("tool.call") as span:
            span.set_attribute("conversation.id", self.conversation_id)
            span.set_attribute("agent.name", self.name)
            span.set_attribute("tool.name", "data_processor")
            span.set_attribute("tool.params", f'{{"data_size": "{data_size}"}}')

            # Simulate processing time based on data size
            size_map = {"small": 0.2, "medium": 1.5, "large": 4.0, "huge": 8.0}
            processing_time = size_map.get(data_size, 1.0)

            time.sleep(processing_time)

            if data_size == "huge" and random.random() < 0.5:
                # Simulate timeout for huge data
                span.set_status(Status(StatusCode.ERROR, "Processing timeout"))

                with tracer.start_as_current_span("error") as error_span:
                    error_span.set_attribute("conversation.id", self.conversation_id)
                    error_span.set_attribute("agent.name", self.name)
                    error_span.set_attribute("error_type", "TimeoutError")
                    error_span.set_attribute("error_message", f"Tool timeout after {processing_time}s")
                    error_span.set_attribute("error_code", "TOOL_TIMEOUT")

                raise Exception(f"Tool timeout after {processing_time}s")

            result = f"Processed {data_size} dataset in {processing_time:.1f}s"
            span.set_attribute("tool.result", result)
            span.set_attribute("tool.status", "success")
            span.set_attribute("tool.execution_time_ms", int(processing_time * 1000))

            return result

# Run problematic scenarios
agent = ProblematicAgent("debug-agent")
agent.start()

test_cases = [
    ("What is machine learning?", "small"),
    ("Explain quantum computing in detail with examples and applications", "medium"),
    ("Analyze this massive dataset with complex algorithms", "large"),
    ("Process enterprise-wide data analytics", "huge"),
]

for prompt, data_size in test_cases:
    try:
        print(f"\nTesting: {prompt[:30]}... with {data_size} data")

        # Try LLM call
        try:
            response = agent.unreliable_llm_call(prompt)
            print(f"LLM Response: {response}")
        except Exception as e:
            print(f"LLM Error: {e}")
            continue  # Skip tool call if LLM fails

        # Try tool call
        try:
            result = agent.memory_intensive_tool(data_size)
            print(f"Tool Result: {result}")
        except Exception as e:
            print(f"Tool Error: {e}")

        time.sleep(0.5)  # Brief pause between tests

    except Exception as e:
        print(f"Unexpected error: {e}")

print(f"\nDebugging session complete. Use conversation ID: {agent.conversation_id}")
time.sleep(2)

    <script>
        let ws = null;
        let metrics = {
            totalEvents: 0,
            errorCount: 0,
            totalTokens: 0,
            responseTimes: []
        };

        function connect() {
            const conversationId = document.getElementById('conversationId').value;
            if (!conversationId) {
                alert('Please enter a conversation ID');
                return;
            }

            if (ws) ws.close();

            ws = new WebSocket(`ws://localhost:8000/ws/${conversationId}`);

            ws.onopen = () => {
                console.log('Connected to debugging session');
            };

            ws.onmessage = (event) => {
                const data = JSON.parse(event.data);
                processEvent(data);
            };
        }

        function processEvent(eventData) {
            metrics.totalEvents++;

            const timestamp = new Date(eventData.timestamp).toLocaleTimeString();
            const eventDiv = document.createElement('div');

            // Categorize and process different event types
            if (eventData.event_type === 'error') {
                metrics.errorCount++;
                eventDiv.className = 'event error';
                eventDiv.innerHTML = `
                    <strong>ERROR</strong> - ${eventData.error_type}<br>
                    ${eventData.error_message}<br>
                    <small>${timestamp}</small>
                `;

                document.getElementById('errors').insertBefore(eventDiv.cloneNode(true),
                    document.getElementById('errors').firstChild);
            }
            else if (eventData.event_type === 'llm.call') {
                const responseTime = eventData.metadata?.response_time_ms;
                if (responseTime) {
                    metrics.responseTimes.push(responseTime);
                }

                const tokens = eventData.tokens?.total || 0;
                metrics.totalTokens += tokens;

                eventDiv.className = responseTime > 2000 ? 'event slow' : 'event success';
                eventDiv.innerHTML = `
                    <strong>LLM CALL</strong> - ${eventData.llm_model}<br>
                    Tokens: ${tokens}, Time: ${responseTime}ms<br>
                    <small>${timestamp}</small>
                `;

                if (responseTime > 2000) {
                    document.getElementById('performance').insertBefore(eventDiv.cloneNode(true),
                        document.getElementById('performance').firstChild);
                }

                // Token usage tracking
                const tokenDiv = document.createElement('div');
                tokenDiv.className = 'event';
                tokenDiv.innerHTML = `${tokens} tokens - ${eventData.prompt?.substring(0, 50)}... <small>${timestamp}</small>`;
                document.getElementById('tokens').insertBefore(tokenDiv,
                    document.getElementById('tokens').firstChild);
            }
            else if (eventData.event_type === 'tool.output') {
                const execTime = eventData.metadata?.execution_time_ms;
                if (execTime && execTime > 3000) {
                    eventDiv.className = 'event warning';
                    eventDiv.innerHTML = `
                        <strong>SLOW TOOL</strong> - ${eventData.tool_name}<br>
                        Execution time: ${execTime}ms<br>
                        <small>${timestamp}</small>
                    `;
                    document.getElementById('performance').insertBefore(eventDiv.cloneNode(true),
                        document.getElementById('performance').firstChild);
                }

                eventDiv.className = 'event success';
                eventDiv.innerHTML = `<strong>TOOL</strong> - ${eventData.tool_name} (${eventData.tool_status}) <small>${timestamp}</small>`;
            }
            else {
                eventDiv.className = 'event';
                eventDiv.innerHTML = `<strong>${eventData.event_type.toUpperCase()}</strong> - ${eventData.agent_name} <small>${timestamp}</small>`;
            }

            // Add to all events
            document.getElementById('allEvents').insertBefore(eventDiv,
                document.getElementById('allEvents').firstChild);

            updateMetrics();
        }

        function updateMetrics() {
            document.getElementById('totalEvents').textContent = metrics.totalEvents;
            document.getElementById('errorCount').textContent = metrics.errorCount;
            document.getElementById('totalTokens').textContent = metrics.totalTokens;

            if (metrics.responseTimes.length > 0) {
                const avgLatency = Math.round(
                    metrics.responseTimes.reduce((a, b) => a + b, 0) / metrics.responseTimes.length
                );
                document.getElementById('avgLatency').textContent = avgLatency;
            }
        }

        function clearAll() {
            document.getElementById('errors').innerHTML = '';
            document.getElementById('performance').innerHTML = '';
            document.getElementById('tokens').innerHTML = '';
            document.getElementById('allEvents').innerHTML = '';

            metrics = {
                totalEvents: 0,
                errorCount: 0,
                totalTokens: 0,
                responseTimes: []
            };
            updateMetrics();
        }
    </script>
