= Install the Agentic Layer

This guide walks you through installing the Agentic Layer's components in dependency
order. Each step links to the component's own install how-to.

== Prerequisites

* A running Kubernetes cluster with `kubectl` configured.
* https://helm.sh/[Helm] 3+ for components that ship as Helm charts.

== Step 1: Install cert-manager

Several operators in the layer require https://cert-manager.io/[cert-manager] for
webhook TLS. Install it first:

[source,bash]
----
kubectl apply -f https://github.com/cert-manager/cert-manager/releases/latest/download/cert-manager.yaml
kubectl wait --for=condition=ready pod -l app.kubernetes.io/name=cert-manager -n cert-manager --timeout=60s
----

Browse all cert-manager releases at https://github.com/cert-manager/cert-manager/releases.

== Step 2: Install the Agent Runtime Operator

The Agent Runtime Operator owns the layer's CRDs (Agent, AgentGateway, AIGateway,
ToolGateway, ToolServer, ToolRoute, Guard, GuardrailProvider, …) used by every other
component. Install it before the gateway operators.

xref:agent-runtime-operator:agent-runtime:how-to-guides/install.adoc[Install the Agent Runtime Operator]

== Step 3: Install gateway operators

Pick one implementation per gateway type. You only need to install the operators for
the gateway types you use. The LiteLLM operator reconciles both `AiGateway` and
`ToolGateway` resources, so a single install can cover both of those gateway types.

[cols="1,3"]
|===
| Gateway type | Implementation install guide

| Agent Gateway
| xref:agent-gateway-krakend-operator::how-to-guides/install.adoc[KrakenD operator]

| AI Gateway
| xref:ai-gateway-litellm-operator::how-to-guides/install.adoc[LiteLLM operator]

| Tool Gateway
a|
* xref:ai-gateway-litellm-operator::how-to-guides/install.adoc[LiteLLM operator]
* xref:tool-gateway-agentgateway::how-to-guides/install.adoc[agentgateway operator]
|===

== Step 4: Install observability (optional)

The Agentic Layer ships an OpenTelemetry-backed dashboard for tracing agent and tool
traffic. See xref:observability-dashboard::how-to-guide.adoc[Deploy and View the Observability Dashboard].

== Verify

Each component's install how-to includes its own verification step. Once every step
above is complete and each component's verification passes, the layer is ready to use.
