Observability Dashboard for Agentic Systems

The Observability Dashboard provides a real-time observability service designed specifically for monitoring complex, multi-agent systems. It ingests OpenTelemetry traces, transforms them into structured communication events, and broadcasts them via WebSocket for live monitoring and analysis.

The primary goal is to solve the observability challenge in agentic systems by providing a centralized hub for understanding agent behavior, communication patterns, and overall system performance.

Key Features

  • Trace Ingestion: Receives OpenTelemetry traces from agent frameworks via OTLP/HTTP

  • Event Processing: Converts raw telemetry spans into structured events (agent lifecycle, LLM calls, tool invocations)

  • Real-time Streaming: Broadcasts processed events to WebSocket clients for live dashboard updates

  • Conversation Filtering: Supports both global event streams and filtering by a specific conversation ID

What is the Observability Dashboard?

The Observability Dashboard acts as a centralized monitoring hub for your agentic systems. It:

  • Ingests telemetry data from your instrumented agent applications

  • Processes traces into meaningful business events

  • Streams events in real-time to connected clients

  • Provides insights into agent behavior and system performance

Architecture Overview

The service operates as a pipeline:

  1. Agent Instruments: Your agentic application emits OpenTelemetry traces

  2. Ingestion: Service receives traces at OTLP/HTTP endpoint

  3. Processing: Core preprocessor transforms spans into structured events

  4. Broadcasting: Events are streamed to WebSocket clients in real-time

Quick Start

To get started with the Observability Dashboard:

  1. Ensure you have the prerequisites installed

  2. Follow the getting started guide to run the service

  3. Configure your agents using the integration guide

  4. Connect to WebSocket streams for real-time monitoring

Use Cases

  • Real-time Monitoring: Watch agent interactions as they happen

  • Debugging: Trace issues through multi-agent conversations

  • Performance Analysis: Monitor LLM calls and tool invocations

  • System Health: Track agent lifecycle events and errors
